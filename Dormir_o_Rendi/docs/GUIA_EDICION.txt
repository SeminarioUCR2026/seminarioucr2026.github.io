GUÍA RÁPIDA DE EDICIÓN

1) Para cambiar las páginas del libro:
   - Entra a assets/img/book/
   - Reemplaza las imágenes cover.jpg, page-2.jpg, page-3.jpg, etc.
   - Si agregas o quitas páginas, edita js/data/book-pages.js

2) Para cambiar el orden del libro:
   - Abre js/data/book-pages.js
   - Cambia el orden de los objetos o añade nuevos.

3) Para editar el juego:
   - Abre js/data/scenes.js

4) Para cambiar estilos:
   - Libro: css/book.css
   - Juego: css/game.css
   - Base general: css/base.css

EFECTO DE LIBRO
- css/book.css contiene el diseño y la animación 3D de las hojas.
- js/book.js controla el avance y retroceso de las páginas.
- Para alterar la duración, cambia BOOK_TURN_TIME (JS) y .95s (CSS).


Imagen principal de la portada: `assets/img/residencia-principal.webp`

IMÁGENES DE LOS DÍAS
assets/img/scenes/lunes-noche.webp = primer día
assets/img/scenes/jueves-fiesta.webp = jueves, fiesta
Para usar imágenes en otros días: js/data/scenes.js (propiedad image de cada día).
