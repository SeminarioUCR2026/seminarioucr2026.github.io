DORMIR O RENDIR - PUBLICACIÓN EN GITHUB PAGES

1. En github.com, crea un repositorio llamado dormir-o-rendir.
2. Extrae este ZIP. Entra en la carpeta descomprimida.
3. Sube el contenido de esa carpeta (incluyendo index.html), no la carpeta entera.
4. GitHub > repositorio > Settings > Pages.
5. Source: Deploy from a branch. Branch: main. Folder: /(root). Save.
6. Abre el enlace que aparece en Pages. Juega los siete días. Al finalizar, el resultado se intentará enviar automáticamente a Discord.

ATENCIÓN:
El webhook es visible en el navegador y GitHub; es SOLO para pruebas.
El envío utiliza no-cors: la página NO puede saber si Discord recibió el mensaje.
Si no aparece en el canal, no des por hecho que funciona. Se necesitará un intermediario.
Antes de uso público, rota el webhook y publícalo únicamente como secreto de un backend.
